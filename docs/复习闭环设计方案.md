## 1. 一句话目标

把已实现但闲置的 SM-2 复习引擎接回 UI：生词页侧栏加「🔁 复习」入口，逐词"翻卡自评"完成今日到期复习，**学习闭环（采集 → 释义 → 复习）收口**。

| 组件 | 状态 | 位置 |
|---|---|---|
| SM-2 引擎 `grade_collect(id, q)` | ✅ 已实现并接线（词卡复习 Tab 在用） | collect.rs:389 / mod.rs:870 |

## 3. 界面设计（三态流转）

见会话内预览图（复习入口界面设计）。要点：

1. **入口**：左侧 Rail 在「历史」与「AI」之间加第 5 项 `🔁 复习`，带红底白字**到期角标**（数字实时取 `stats().due`）；`RailItem` 组件需扩展可选 badge 参数。
2. **状态① 摘要页**（进入即显）：大数字到期数 + 生词本概况（总数/已熟练/平均熟练度）+「开始复习」主按钮；到期数为 0 时显示"今日已完成 ✓ 明天再来"。
3. **状态② 正面**：单词 + 音标 + 🔊（复用 TTS 路径）+ 档位/学科徽章 + 进度条（N/total）+「显示答案」。
4. **状态③ 答案面**：中文释义（大字）→ 英英释义首行 → 📌 采集原句 → 🧩 词根拆解 → 四档自评按钮（忘记0/模糊3/记得4/容易5，配色与词卡复习 Tab 一致）。
5. 评分后**自动推进下一词**；队列走完回摘要页并显示本次小结。

三态用同一抽屉容器 + `review-phase`（0 摘要 / 1 正面 / 2 答案面）切换，样式全部走现有主题令牌（A–F 自动跟随）。

## 4. 数据流与新增接线

```
Rail「🔁」 clicked
  → open-drawer("review")
  → mod.rs on_open_drawer 分支加 "review"：invoke load-review
      cb.get_review_queue() → 填 review_rows / review_ids
      cb.stats() → due 填 review_due + Rail 角标 review_badge
翻面   → review-flip()：phase 1 ↔ 2（纯 UI）
自评   → review-grade(idx, q)：cb.grade_collect(id, q)（复用词卡同款）
      → 从模型移除该行、done+1、自动切下一词 phase=1
完成   → 队列空 → phase=0 + 小结文案 + 刷新角标
发音   → review-tts()：复用 word-card-play-tts 的 TTS 路径（取当前词）
```

**新增 slint 属性/回调**（真源 `gen_slint_v2.py`，勿手改 slint）：

| 类别 | 名称 | 说明 |
|---|---|---|
| 属性 | `review-rows / review-ids` | 队列模型（行文本 + id） |
| 属性 | `review-idx / review-phase / review-due / review-total` | 位置 / 三态 / 到期数 |
| 属性 | 当前词五件套 | word / phonetic / translation / definition-en / example / roots（答案面用，open 复制自 collect item） |
| 回调 | `review-start() / review-flip() / review-grade(int) / review-tts()` | 四个动作 |
| 属性 | `review-badge` | RailItem 角标数字（-1 = 不显示） |

**mod.rs 接线**约 4 块（load / grade / tts / open-drawer 分支），全是对现有方法的调用，无新 SQL。

## 5. 实施分期

| 期 | 内容 | 规模 | 验收 |
|---|---|---|---|
| **M1（本期）** | Rail 入口+角标、抽屉三态、队列加载、翻面、四档自评、自动推进、完成小结 | slint ~120 行 + mod.rs ~90 行 | `cargo run` 后：有到期词时角标显示数字 → 开始 → 翻面 → 评分 → 队列清零 → 角标归零；评分后词卡熟练度/下次复习时间同步变化 |
| M2 | 摘要页统计增强（平均熟练度、各档分布）、`stats()` due 丢值处清理、键盘快捷键（空格翻面 / 1–4 评分） | ~50 行 | 键盘全流程可用 |
| M3 | 扩展侧联动：popup 显示"今日到期 N"（经 host `list_collect` 不够，需 host 加 `review_queue` 动作）、气泡窗口入口 | host ~40 行 + 扩展 ~60 行 | 浏览器侧可见并跳转复习 |

## 6. Non-goals（本期不做）

- 不做自定义复习算法参数（SM-2 默认参数已够，调参属过度设计）
- 不做拼写测试 / 选择题模式（交互复杂度不成比例，翻卡自评是 Anki 验证过的最小闭环）
- 不做复习日历热图（数据量不足时是空架子）
- 不做跨设备同步（桌面端唯一真源已拍板）

## 7. 风险与对策

| 风险 | 对策 |
|---|---|
| 到期数为 0 时入口显得死 | 空态文案引导"先去采集/补全释义"；角标 0 时不显示 |
| 复习中断（关抽屉/关程序） | 队列每词即时写库（grade_collect 本就落库），重进按 SM-2 队列重新拉取，无会话状态依赖 |
| RailItem 组件改动影响其他四项 | badge 参数默认 -1 不渲染，现有项零改动 |
