欢迎使用 WinOCR-Html

一个全场景 OCR 翻译工具：截图翻译、浏览器划词/悬停翻译、本地模型离线可用。

下面 5 步只需 1 分钟，每一步都可跳过；全程不索取任何 API Key 也能用。

免费引擎（无需 Key）· 推荐起步
MyMemory / 浏览器内置：零配置、国内可直连、匿名即用。额度用尽会自动提示。
SiliconFlow（质量更好 · 需自备 Key）
填你自己的 Key 即可，费用归你；不填也能先用免费引擎。

Key 仅存于本机，经系统加密（DPAPI）落盘，不会上传给任何人。

Alt+Q 唤起截图选区
Ctrl+Alt+Q 退出宿主
Ctrl+Alt+P 暂停 / 恢复

浏览器内划词翻译用扩展快捷键（Alt+Shift+Z），可在 edge://extensions/shortcuts 修改。

这些键都能在「设置 → 截图热键」里重新录入并即时生效，不习惯现在也不用改。

tiny 模型（6.6MB，已内置）
离线即可 OCR，约 1.2–2.2 秒，日常够用。推荐起步。
medium 模型（更准 · 需另下载 133MB）
复杂版面/手写更稳；可在设置里「下载语言包」按需获取。

无网络环境下 tiny 已随安装包内置；选 medium 只是晚一点下载，不影响现在使用。
