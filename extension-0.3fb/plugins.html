设计目标：以自有代码实现扩展点，不复制 Pot / Bob 的专有源码；但插件描述格式将兼容 Pot / Bob 的 manifest 约定（如 plugin.json 的 name / description / entry / hooks 字段），便于社区迁移现有插件。

暴露的钩子（规划中）：translate.before / translate.after（改写请求与结果）、ocr.after（后处理识别文本）、tts.before（朗读前替换）、selection.action（划词动作扩展）。宿主侧将在 Rust 暴露对应的 action 钩子，扩展侧通过 content script 注入点挂载。
