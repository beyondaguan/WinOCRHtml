截图翻译（Alt+Q 原生宿主）

只作用于 Alt+Q 截图 OCR 之后的翻译；网页划词翻译用页面顶部的「翻译引擎」下拉（两份开关互不影响）。 各引擎复用上方同一组输入框（SF Key、MyMemory 邮箱）。
扩展联动（NM 模式）下点「保存」会即时同步给宿主并落盘到 winocr_config.json； 独立模式（run_host.bat）直接读该文件，手改后重启宿主生效。

截图热键（原生宿主）


自由录入：点上面的输入框 → 直接按下想要的组合键即可（例如 Ctrl+Alt+M、Alt+Shift+F9）。 支持 Ctrl / Alt / Shift / Win + 字母 / 数字 / F1–F24。录好后点「保存」，扩展会把热键同步给原生宿主并即时重新注册 （宿主没运行则只存进配置，下次启动生效）。
退出热键（默认 Ctrl+Alt+Q）：一按就关掉当前持有热键的宿主； 允许同时运行多个宿主（热键由最旧的实例持有），连按可逐个关闭直到全关； 也可以双击 stop_host.bat 一次全部关掉。 注意 不能用裸 Esc —— 全局注册裸 Esc 会劫持全系统的 Esc（对话框/游戏/浏览器全都失效），所以退出键必须带修饰键。
⚠️ 默认 Ctrl+Shift+M 与 WinOCR 3.4 的蒙版翻译冲突，建议改成 Ctrl+Alt+M。
扩展自身的快捷键（Alt+Shift+W / Alt+Shift+Z）Chrome 不允许扩展修改，需到 edge://extensions/shortcuts 手动改。
「常驻翻译栏」在原文位置显示 原文 + 译文，可拖动、点 × 关闭。
